# 10 — State, Memory, and Provenance

Context separates conversation state, SAMI reconciled resident state, retrieved Thoth memory, authoritative MAAT state, model inference, and tool results. Claims carry provenance class where material.

SAMI resident brief is **situational context**, not memory authority. Its queues and counts are projections over underlying estate systems and MUST retain their source boundaries.

Long-term runtime memory ownership remains Thoth. Proof-backed execution lineage is persisted through native Thoth post-proof memory from `estate_proof_receipts`; Atlas Mind MUST NOT create canonical runtime memory merely because a SAMI observation exists.

Normal production memory flow:

`Execution -> ProofGrid -> runtime-execution-receipt -> native Thoth persistence -> SAMI reconciliation -> Atlas Mind context`

Atlas Mind may produce memory candidates, but canonical long-term memory writes remain subject to Thoth policy. Conversation text, model inference, SAMI projections, and unproven completion claims are not automatically canonical memory.

Historical or non-runtime evidence may be preserved without being promoted. `PRESERVE != PROMOTE`.
