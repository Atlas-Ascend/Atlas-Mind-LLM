## Executive definition

There is one canonical Atlas Mind identity.

Model Zero, Atlas Mind V2, V3, V4, Atlas Mind 3.0, and OMNIMIND references are preserved as historical lineage, compatibility coordinates, surfaces, or subordinate cognitive capabilities. They are not authorized to become competing Atlas identities or separate replacement runtimes.

The machine-readable authority for this rule is `ATLAS_MIND_RUNTIME_BINDING.json`.

## Canonical owner split

- `Atlas-Ascend/Atlas-Mind-LLM` owns Atlas Mind identity, product/cognition contracts, historical lineage, and public product truth.
- `Atlas-Ascend/Eden-2.0/atlas-mind-runtime` owns the persistent local identity runtime and proof-backed learning scaffold.
- GA-NIF owns processor discovery and inference routing. A selected model is a processor, not Atlas Mind identity.
- `scripts/atlas_mind_office_fabric_ingress.py` remains the existing Office Fabric/context integration and universal instrumentation mount.
- `scripts/atlas_mind_converged_ingress.py` is the thin convergence adapter over that existing ingress. It does not replace Office Fabric, GA-NIF, Atlas Mind runtime, JANUS, Workforce, THOTH, or EDEN.
- JANUS/ODIN owns state-changing authority.
- Packet OS and Workforce Spine own durable executable work.
- EDEN owns physical/local execution.
- SECA/DevOS and ProofGrid own verification and proof.
- THOTH owns durable memory/provenance continuity.

## Lineage disposition

### Model Zero

Preserved as ancestral model/training provenance. Old callers may resolve the label to the current Atlas Mind identity, but no claim is made that current inference uses historical Model Zero weights.

### Atlas Mind V2

Preserved as operational identity/RAG/training-packet lineage and compatibility alias. Requests using the V2 identity label resolve to canonical `atlas-mind`.

### Atlas Mind V3

Preserved as desktop command surface and cognition lineage. V3 Desktop is an operator surface over Atlas Mind, not a second brain.

### Atlas Mind V4

Preserved as a compatibility coordinate for promoted capability-profile lineage. The runtime does not create a fourth assistant or bind identity to a V4-specific processor.

### Atlas Mind 3.0

Current product contract over the same persistent identity. 3.0 capability compression upgrades routing, context, tools, memory discipline, multimodality, evaluation, installation and recovery without replacing canonical owners.

### OMNIMIND

Preserved as a subordinate cognitive compatibility coordinate inside the Atlas/Trifinity architecture. It does not supersede Atlas Mind identity or JANUS authority.

### VEVR

`FORENSIC_HOLD`. Original source authority has not yet established whether VEVR is a model lineage, verification construct, or runtime/surface. The converged runtime therefore fails closed on VEVR identity requests rather than inventing its meaning.
